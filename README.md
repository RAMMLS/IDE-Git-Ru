# IDE-Git-Ru
Пилим свой аналог гитхаба внутри IDE



# Структура хранения текста:

Хранить все в виде строки тяжело, используем Rope || Gap Buffer 
Либры для структур: ropey или xi-rope

## UI 
1. TUI - терминал (вим, неовим, нано и прочие) 
    Либры: ratatui + crossterm (проще для старта)
2. GUI - приложение (вс код, вс студио и прочие)
    Либры: egui, iced, tauri



# 1. Состояние (Struct) - сердце IDE

Для IDE надо знать параметры: 
1. Какой текст в редакторе
2. Какой файл открыт
3. Изменен ли файл
